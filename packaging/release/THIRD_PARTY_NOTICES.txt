About the program / О программе
-------------------------------
The portable version needs no installed Python. Settings and journals
are kept in %LOCALAPPDATA%\DownloadsOrganizer. Version 1.0.0 only MOVES
files within one volume: copying between volumes is disabled. Completed
moves are not undone automatically; files can be moved back by hand
using the journal. Details: README_EN.txt, RELEASE_NOTES.txt.
Портативной версии не нужен установленный Python. Настройки и журналы
хранятся в %LOCALAPPDATA%\DownloadsOrganizer. Версия 1.0.0 только
ПЕРЕМЕЩАЕТ файлы внутри одного тома: копирование между томами
отключено. Выполненные перемещения не отменяются автоматически; вернуть
файлы можно вручную по журналу. Подробнее: README_RU.txt,
RELEASE_NOTES.txt.
